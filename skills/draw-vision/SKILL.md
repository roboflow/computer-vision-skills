# Draw Vision

Use the library that matches the implementation environment when drawing computer
vision annotations over images or videos, including model outputs and ground truth.

## Choose the library

- **JavaScript, TypeScript, HTML, or browser UI:** use
  [supervision-js](https://github.com/roboflow/supervision-js).
  Read its [documentation](https://roboflow.github.io/supervision-js/).
- **Python:** use [Supervision](https://github.com/roboflow/supervision).
  Read its [documentation](https://supervision.roboflow.com/latest/).

## Follow upstream guidance

If a relevant library usage skill is installed, read and apply it. Otherwise,
check the corresponding upstream repository for usage skills and follow them
when available; use the official documentation for the APIs you need.

Keep library-specific instructions upstream rather than duplicating them here.
